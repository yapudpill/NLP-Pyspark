## Dependencies

Make sure to have Java between 11 and 17 with the `JAVA_HOME` environment
variable to the path of your Java installation. You also need python between
3.11 and 3.13 installed on your machine. Then, you can install the required
python packages with:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```
